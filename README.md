This program (`main.py`, Python 3.13, standard library only) writes one short poem as UTF-8 with no trailing newline to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set; run it with `python3 main.py` (for example `MAKEFUN_OUTPUT_DIR=out/a python3 main.py`). The text, 164 Unicode code points, is:

```
The agent asks: Send?
I click yes
and keep my hand on the mouse,
the way it stayed out at the kerb
the morning my daughter crossed alone,
holding the shape of hers.
```
