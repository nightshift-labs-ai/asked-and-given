The text, 267 Unicode code points, is:

```
Can I carve this year?
He wiped the knife on his apron
and turned it around,
bone handle warm from his palm,
blade toward himself,
the way he taught me to pass scissors.
Then he walked the long way round the table,
scraped back a guest's chair
and held out his plate.
```
